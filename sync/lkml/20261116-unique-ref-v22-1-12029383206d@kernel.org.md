# [PATCH v22 1/5] rust: alloc: add `KBox::into_non_null`

来源：[https://lore.kernel.org/linux-block/20261116-unique-ref-v22-1-12029383206d@kernel.org/](https://lore.kernel.org/linux-block/20261116-unique-ref-v22-1-12029383206d@kernel.org/)

```
Add a method to consume a `Box<T, A>` and return a `NonNull<T>`. This
is a convenience wrapper around `Self::into_raw` for callers that need
a `NonNull` pointer rather than a raw pointer.

         // which points to an initialized instance of `T`.

     }
+
+    /// Consumes the `Box<T, A>` and returns a `NonNull<T>`.
+    ///
+    /// Like [`Self::into_raw`], but returns a `NonNull`.
+    #[inline]
+    pub fn into_non_null(b: Self) -> NonNull<T> {
+        // SAFETY: `Box::into_raw` returns a valid pointer.
+        unsafe { NonNull::new_unchecked(Self::into_raw(b)) }
+    }
 }
```
