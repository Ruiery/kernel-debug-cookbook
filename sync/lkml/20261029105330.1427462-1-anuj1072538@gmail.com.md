# [PATCH] block: don't use the bvec fast path for dma-buf bios

来源：[https://lore.kernel.org/linux-block/20261029105330.1427462-1-anuj1072538@gmail.com/](https://lore.kernel.org/linux-block/20261029105330.1427462-1-anuj1072538@gmail.com/)

```
From: Anuj Gupta <anuj20.g@samsung.com>

bio_may_need_split() reads bi_io_vec, which for dma-buf bios aliases
bi_dmabuf_map, and interprets the map as a bvec. Always run the full
split check for dma-buf bios.

Fixes: d88e44f43e93 ("block: introduce dma map backed bio type")
Signed-off-by: Anuj Gupta <anuj20.g@samsung.com>
```
