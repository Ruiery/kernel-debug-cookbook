# [PATCH 1/2] zsmalloc: fix SPDX license identifier

来源：[https://lore.kernel.org/linux-block/39f6056e0c8834fc3eca2001fcb44f3b6048f74d.1795061575.git.senozhatsky@chromium.org/](https://lore.kernel.org/linux-block/39f6056e0c8834fc3eca2001fcb44f3b6048f74d.1795061575.git.senozhatsky@chromium.org/)

zsmalloc is released under MODULE_LICENSE("Dual BSD/GPL") so
the existing SPDX license identifier is incorrect.

Use the matching identifier, (GPL-2.0-only OR BSD-3-Clause),
and drop the license text that it replaces.  The copyright
notices stay as they are.

Signed-off-by: Sergey Senozhatsky <senozhatsky@chromium.org>
