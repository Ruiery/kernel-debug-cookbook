# [PATCH 11/17] find: micro-optimize for_each_{set,clear}_bit()

来源：[https://lore.kernel.org/linux-mm/20210814211713.180533-12-yury.norov@gmail.com/](https://lore.kernel.org/linux-mm/20210814211713.180533-12-yury.norov@gmail.com/)

```
The macros iterate thru all set/clear bits in a bitmap. They search a
first bit using find_first_bit(), and the rest bits using find_next_bit()=
.

Since find_next_bit() is called shortly after find_first_bit(), we can
save few lines of I-cache by not using find_first_bit().

Signed-off-by: Yury Norov <yury.norov@gmail.com>
Tested-by: Wolfram Sang <wsa+renesas@sang-engineering.com>
```
