# [PATCH v2 12/61] xen/privcmd: Optimized privcmd_ioctl_mmap() by using vma_lookup()

来源：[https://lore.kernel.org/linux-mm/20210817154651.1570984-13-Liam.Howlett@oracle.com/](https://lore.kernel.org/linux-mm/20210817154651.1570984-13-Liam.Howlett@oracle.com/)

```
From: "Liam R. Howlett" <Liam.Howlett@Oracle.com>

vma_lookup() walks the VMA tree for a specific value, find_vma() will
search the tree after walking to a specific value.  It is more efficient
to only walk to the requested value as this case requires the address to
equal the vm_start.

Signed-off-by: Liam R. Howlett <Liam.Howlett@Oracle.com>
```
