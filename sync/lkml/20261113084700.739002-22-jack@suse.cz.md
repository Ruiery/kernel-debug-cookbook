# [PATCH 09/13] gfs2: Fix dirtiness checks in gfs2_write_inode() and evict_linked_inode()

来源：[https://lore.kernel.org/linux-block/20261113084700.739002-22-jack@suse.cz/](https://lore.kernel.org/linux-block/20261113084700.739002-22-jack@suse.cz/)

```
The checks are bogus because they check against inode->i_flags instead
of inode->i_state. Use the inode_or_folios_dirty() helper which actually
checks what was intended.

Signed-off-by: Jan Kara <jack@suse.cz>
---
```
