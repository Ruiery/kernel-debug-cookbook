# [PATCH v2 03/11] zsmalloc: return handle from obj_allocated()

来源：[https://lore.kernel.org/linux-block/20261110054836.1515030-4-senozhatsky@chromium.org/](https://lore.kernel.org/linux-block/20261110054836.1515030-4-senozhatsky@chromium.org/)

```
Allocated handles are valid kernel addresses and never 0, so let
obj_allocated() return the handle directly (or 0 if unallocated)
instead of returning a bool.

No functional change.

Suggested-by: Yosry Ahmed <yosry@kernel.org>
Signed-off-by: Sergey Senozhatsky <senozhatsky@chromium.org>
```
