# [PATCH 07/17] all: replace find_next{,_zero}_bit with find_first{,_zero}_bit where appropriate

来源：[https://lore.kernel.org/linux-mm/20210814211713.180533-8-yury.norov@gmail.com/](https://lore.kernel.org/linux-mm/20210814211713.180533-8-yury.norov@gmail.com/)

```
find_first{,_zero}_bit is a more effective analogue of 'next' version if
start =3D=3D 0. This patch replaces 'next' with 'first' where things look
trivial.

Signed-off-by: Yury Norov <yury.norov@gmail.com>
Tested-by: Wolfram Sang <wsa+renesas@sang-engineering.com>
```
