# [PATCH 11/13] nfsd: Use inode_or_folios_dirty() for dirtiness check in wait_for_concurrent_writes()

来源：[https://lore.kernel.org/linux-block/20261113084700.739002-24-jack@suse.cz/](https://lore.kernel.org/linux-block/20261113084700.739002-24-jack@suse.cz/)

```
The check for dirtiness in wait_for_concurrent_writes() is racy because
I_DIRTY_PAGES flag can be temporarily cleared by
__writeback_single_inode(). Use inode_or_folios_dirty() helper to avoid
that. This also makes sure inode timestamps properly persisted when
lazytime is enabled.

Signed-off-by: Jan Kara <jack@suse.cz>
```
