# [PATCH 03/13] orangefs: Check PAGECACHE_TAG_DIRTY instead of I_DIRTY_PAGES inode state

来源：[https://lore.kernel.org/linux-block/20261113084700.739002-16-jack@suse.cz/](https://lore.kernel.org/linux-block/20261113084700.739002-16-jack@suse.cz/)

```
PAGECACHE_TAG_DIRTY is the authoritative source of dirty folios present
in the mapping. Use that instead of looking at I_DIRTY_PAGES inode state
which can get stale (e.g. when folios are written directly with
filemap_fdatawrite()).

Signed-off-by: Jan Kara <jack@suse.cz>
```
