# [PATCH 13/98] blk-cgroup: fix root io.stat byte counts on 32-bit

来源：[https://lore.kernel.org/linux-block/20261028164415.1262013-14-axboe@kernel.dk/](https://lore.kernel.org/linux-block/20261028164415.1262013-14-axboe@kernel.dk/)

```
From: Josef Bacik <josef@toxicpanda.com>

blkcg_fill_root_iostats() shifts the unsigned long sector counts by 9
before adding them to the u64 byte counts, so on 32-bit the contribution
of a CPU wraps every 4GB. Widen before the shift.

Fixes: ef45fe470e1e ("blk-cgroup: show global disk stats in root cgroup io.stat")
Cc: Tejun Heo <tj@kernel.org>
Signed-off-by: Josef Bacik <josef@toxicpanda.com>
Signed-off-by: Jens Axboe <axboe@kernel.dk>
```
