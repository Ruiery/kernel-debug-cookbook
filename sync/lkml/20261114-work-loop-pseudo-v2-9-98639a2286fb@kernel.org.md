# [PATCH RFC v2 09/42] bpf: use fc_init_pseudo() for bpffs

来源：[https://lore.kernel.org/linux-block/20261114-work-loop-pseudo-v2-9-98639a2286fb@kernel.org/](https://lore.kernel.org/linux-block/20261114-work-loop-pseudo-v2-9-98639a2286fb@kernel.org/)

SB_I_NOEXEC and SB_I_NODEV by hand. This adds SB_I_PSEUDO.
