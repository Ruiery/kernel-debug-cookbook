# [PATCH 2/2] zram: lz4/lz4hc: accept dictionaries of more than 64 KiB

来源：[https://lore.kernel.org/linux-block/f2ac22a731e507e90217a5e9cf29c987ec24e2b0.1793333729.git.senozhatsky@chromium.org/](https://lore.kernel.org/linux-block/f2ac22a731e507e90217a5e9cf29c987ec24e2b0.1793333729.git.senozhatsky@chromium.org/)

From: Josef Bacik <josef@toxicpanda.com>

From: Josef Bacik <josef@toxicpanda.com>

LZ4_loadDict() and LZ4_loadDictHC() only use the last 64KiB of a
dictionary and return how much they used, which the zram backends
take for an error.  Expect that instead.

Signed-off-by: Josef Bacik <josef@toxicpanda.com>
Signed-off-by: Sergey Senozhatsky <senozhatsky@chromium.org>
