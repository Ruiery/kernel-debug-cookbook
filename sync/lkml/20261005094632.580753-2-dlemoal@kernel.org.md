# [PATCH 1/7] block: fail reads to offline zones early

来源：[https://lore.kernel.org/linux-block/20261005094632.580753-2-dlemoal@kernel.org/](https://lore.kernel.org/linux-block/20261005094632.580753-2-dlemoal@kernel.org/)

```
Any BIO targeting an offline zone of a zoned block device will fail,
including read commands. So there is no point in issuing read BIOs.
Fail these early if we ever see one, and be quiet about the error.

Signed-off-by: Damien Le Moal <dlemoal@kernel.org>

+	enum blk_zone_cond cond;
```
