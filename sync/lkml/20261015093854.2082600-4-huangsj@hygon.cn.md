# [PATCH 3/3] vfs: convert sb->s_inodes iteration to super_iter_inodes()

来源：[https://lore.kernel.org/linux-block/20261015093854.2082600-4-huangsj@hygon.cn/](https://lore.kernel.org/linux-block/20261015093854.2082600-4-huangsj@hygon.cn/)

```
Convert all the remaining superblock inode iterators to use
super_iter_inodes(). These are mostly straight forward conversions
for the iterations that use referenced inodes:
 - sync_bdevs
 - drop_pagecache_sb
 - gfs2_kill_sb
 - add_dquot_ref
 - hook_sb_delete
```
