# [PATCH v7 05/15] zram: remove stale WARN_ON() from zram_read_page()

来源：[https://lore.kernel.org/linux-block/20261025021839.1542805-6-senozhatsky@chromium.org/](https://lore.kernel.org/linux-block/20261025021839.1542805-6-senozhatsky@chromium.org/)

```
The zram_read_page() WARN_ON() is not accurate anymore, because, in
theory, async read from bdev can return -EIO or -ENOMEM.  We report
errors to upper layers via bi_status, so upper layers printk errors.

Signed-off-by: Sergey Senozhatsky <senozhatsky@chromium.org>
```
