来源：[https://lore.kernel.org/linux-block/20261125083947.263216-3-afaria@redhat.com/](https://lore.kernel.org/linux-block/20261125083947.263216-3-afaria@redhat.com/)

```
Expose VIRTIO_BLK_F_REQ_FLAGS and VIRTIO_BLK_F_REQ_FLAGS_OUT_FUA to
drivers. The simulator is a ramdisk, so it handles FUA and non-FUA
writes in the same way.
```
