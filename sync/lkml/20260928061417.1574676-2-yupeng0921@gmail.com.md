# [PATCH v6 1/3] cgroup: track the effective css in each cgroup

来源：[https://lore.kernel.org/linux-block/20260928061417.1574676-2-yupeng0921@gmail.com/](https://lore.kernel.org/linux-block/20260928061417.1574676-2-yupeng0921@gmail.com/)

```
Track the effective css in each cgroup and make cgroup_e_css() and
cgroup_get_e_css() use it. When a css is brought online or offline,
update the effective css of its cgroup and of all descendants.
```
