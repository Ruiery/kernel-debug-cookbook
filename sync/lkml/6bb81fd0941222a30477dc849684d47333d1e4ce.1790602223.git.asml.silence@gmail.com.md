# [PATCH v7 11/13] io_uring/rsrc: add uncloneable regbuf flag

来源：[https://lore.kernel.org/linux-block/6bb81fd0941222a30477dc849684d47333d1e4ce.1790602223.git.asml.silence@gmail.com/](https://lore.kernel.org/linux-block/6bb81fd0941222a30477dc849684d47333d1e4ce.1790602223.git.asml.silence@gmail.com/)

```
It's hard to implement cloning if the internal structure needs to be
mutable and/or relies on other ring resources. In preparation to such
buffer types, add a flag indicating that the buffer can't be cloned. It
might be possible to add cloning in the future for them, but that would
likely need reallocating the structure and reacquiring resources in case
by case manner.

Signed-off-by: Pavel Begunkov <asml.silence@gmail.com>
```
