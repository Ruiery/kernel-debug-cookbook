# [PATCH blktrace 4/6] blktrace: mask __BLK_TA_IOPRIO when decoding actions

来源：[https://lore.kernel.org/linux-block/20261124134602.153239-5-johannes.thumshirn@wdc.com/](https://lore.kernel.org/linux-block/20261124134602.153239-5-johannes.thumshirn@wdc.com/)

```
__BLK_TA_IOPRIO is a flag in the action, like __BLK_TA_CGROUP, so it has
to be masked out wherever the action is decoded: in blkparse, btt,
iowatcher and btrecord. btt and btrecord did not mask __BLK_TA_CGROUP
either, so mask both there.

Signed-off-by: Johannes Thumshirn <johannes.thumshirn@wdc.com>
```
