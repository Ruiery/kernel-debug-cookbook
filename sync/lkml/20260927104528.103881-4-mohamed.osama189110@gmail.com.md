来源：[https://lore.kernel.org/linux-block/20260927104528.103881-4-mohamed.osama189110@gmail.com/](https://lore.kernel.org/linux-block/20260927104528.103881-4-mohamed.osama189110@gmail.com/)

```
Replace the ScopeGuard usage in the serial device bus implementation
with DropGuard.

Use DropGuard::dismiss() when ownership of the private data needs to be
transferred without running the cleanup callback.
```
