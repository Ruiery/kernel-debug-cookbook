来源：[https://lore.kernel.org/linux-mm/20210813063150.2938-5-alex.sierra@amd.com/](https://lore.kernel.org/linux-mm/20210813063150.2938-5-alex.sierra@amd.com/)

```
When CPU is connected throug XGMI, it has coherent
access to VRAM resource. In this case that resource
is taken from a table in the device gmc aperture base.
This resource is used along with the device type, which could
be DEVICE_PRIVATE or DEVICE_GENERIC to create the device
page map region.
```
