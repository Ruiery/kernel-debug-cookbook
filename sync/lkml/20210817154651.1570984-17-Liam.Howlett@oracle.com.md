# [PATCH v2 16/61] mm: Use maple tree operations for find_vma_intersection() and find_vma()

来源：[https://lore.kernel.org/linux-mm/20210817154651.1570984-17-Liam.Howlett@oracle.com/](https://lore.kernel.org/linux-mm/20210817154651.1570984-17-Liam.Howlett@oracle.com/)

From: "Liam R. Howlett" <Liam.Howlett@Oracle.com>

Move find_vma_intersection() to mmap.c and change implementation to
maple tree.

When searching for a vma within a range, it is easier to use the maple
tree interface.  This means the find_vma() call changes to a special
case of the find_vma_intersection().

Exported for kvm module.

Signed-off-by: Liam R. Howlett <Liam.Howlett@Oracle.com>
