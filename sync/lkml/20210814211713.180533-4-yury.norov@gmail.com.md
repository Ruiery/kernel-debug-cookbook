# [PATCH 03/17] include: move find.h from asm_generic to linux

来源：[https://lore.kernel.org/linux-mm/20210814211713.180533-4-yury.norov@gmail.com/](https://lore.kernel.org/linux-mm/20210814211713.180533-4-yury.norov@gmail.com/)

```
find_bit API and bitmap API are closely related, but inclusion paths
are different - include/asm-generic and include/linux, correspondingly.
In the past it made a lot of troubles due to circular dependencies
and/or undefined symbols. Fix this by moving find.h under include/linux.

Signed-off-by: Yury Norov <yury.norov@gmail.com>
Tested-by: Wolfram Sang <wsa+renesas@sang-engineering.com>
```
